# Changelog for ndx-facemap-motionsvd

## 0.2.0 (Unreleased)

- `MotionSVDMasks` gains three optional fields: `average_motion`, the per-pixel mean motion
  Facemap subtracts before the decomposition; a `singular_value` column with one value per
  component; and a `source_video` link to the `ImageSeries` the decomposition was computed from.
- `mask_coordinates` is documented as `[row_start, column_start, row_end, column_end]` and
  `processed_frame_dimension` as `[height, width]`, which is what files written with 0.1.0
  hold. `MotionSVDMasks.add_row` rejects a mask whose shape is not the size of its box, or a
  box that does not fit in the frame.
- The spec is generated by `src/spec/create_extension_spec.py`.
- Requires `pynwb>=3.0.0` and `hdmf>=4.0.0`, the first releases that work with NumPy 2.
- First release on PyPI. Version 0.1.0 was never released there; it is the version embedded
  in the files of DANDI:001172.
